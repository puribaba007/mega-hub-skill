# Security Policy

## Scope
Mega Hub ships **instructions and catalogs**, not a running service. The main risks are:
- a wrong install command or connector URL pointing somewhere unexpected, or
- a listed third-party plugin/connector/tool behaving badly (report upstream too).

## Reporting
Found a problem — a bad/malicious entry, a wrong URL, or anything unsafe?
- Open a **private security advisory** on this repo (Security → Report a vulnerability), or
- Open a normal issue if it is not sensitive.

Please do **not** include secrets (API keys, tokens, passwords) in reports.

## What we will do
We triage promptly, remove or fix unsafe entries, and credit reporters who want it.

## User safety notes
- Connectors use **your own sign-in** — review each service's permissions before connecting.
- Trading skills default to **paper**; money-moving actions always require your explicit confirmation.
- `code-forge` reverse-engineering / Replica are for **authorized, CTF and learning** use only.
