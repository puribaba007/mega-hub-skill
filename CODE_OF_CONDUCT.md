# Code of Conduct

## Our pledge
We want Mega Hub to be a friendly, harassment-free project for everyone, regardless of
experience, background or identity.

## Expected behavior
- Be respectful and constructive.
- Assume good intent; give and accept feedback gracefully.
- Keep contributions accurate, legal and ethical.

## Unacceptable behavior
- Harassment, insults, or discrimination of any kind.
- Sharing others' private information.
- Submitting malicious code, or tools intended for unauthorized access, piracy or deception.

## Enforcement
Maintainers may remove, edit or reject contributions and comments that violate this code,
and may block repeat offenders. Report issues by opening a private security advisory or an issue.

This Code of Conduct is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
