# Connectors (MCP) — 140+ from the official Claude connector registry

All entries below were pulled from the Claude MCP registry (Oct 2026). Connecting is free;
the service behind it may need its own account or paid plan.
**How to add:** Claude app → Settings → Connectors → search the name → Connect (sign in with the
service). In a terminal: `claude mcp add --transport http <name> <url>` then `/mcp` to sign in.
Tip: ask Claude "list my connectors" to see which ones you already have.
